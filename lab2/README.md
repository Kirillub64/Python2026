## Ответы на вопросы для защиты

### 1. Чем `/` отличается от `//`?

- `/` — обычное деление, результат всегда `float` (даже `10 / 2 = 5.0`).
- `//` — целочисленное деление с округлением **вниз**: `10 // 3 = 3`, `-7 // 2 = -4`.

### 2. В чём смысл остатка `%`?

Остаток показывает, сколько «лишнего» осталось после выделения целой части.
Связь: `a == (a // b) * b + a % b` при `b != 0`.
Пример: `21 % 10 = 1` — после двух подносов по 10 осталась 1 порция.

### 3. Почему форматирование не устраняет неточность `float`?

Формат `:.2f` только **округляет при выводе**, но не меняет хранимое значение.
Пример: `0.1 + 0.2` в памяти — это `0.30000000000000004`. Если вывести `:.2f`, увидим `0.30`, но в вычислениях число остаётся неточным.
Поэтому в задачах о деньгах мы используем целые числа (рубли, копейки).
