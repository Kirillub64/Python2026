# Лабораторная работа 1. Первые программы на Python

**Вариант 15 — Туристический магазин (Фонарики и Компасы)**

## Как запустить

Каждый файл запускается в IDLE клавишей F5 (Run → Run Module).
Или через командную строку:

    python имя_файла.py

## Файлы

- `hello.py` — первая программа (подготовка)
- `profile.py` — задание 1: карточка студента
- `workload.py` — задание 2: учебная нагрузка
- `debug.py` — задание 3: исправление ошибок
- `swap.py` — задание 4: обмен значениями
- `variant.py` — индивидуальный вариант 15

## Проверки

### profile.py
- Возраст 18 → через 4 года 22
- 2 ч/нед → 8.00 ч за 4 недели, 1.14 ч в день
- 0 часов → 0.00 и 0.00

### workload.py
- История: 2 × 135 = 270 мин
- Физика: 2 × 135 = 270 мин
- Всего: 540 мин = 9.00 ч
- Свободно 12 ч → остаток 3.00 ч
- За 4 недели: 36.00 ч

### debug.py
- А. Сумма: 5
- Б. Возраст через год: 18
- В. Среднее: 7.0

### swap.py
- До обмена: 227 и 401
- После обмена: 401 и 227
- Одинаковые значения остаются одинаковыми

### variant.py (вариант 15)
- Фонарики: 3 × 12.50 = 37.50
- Компасы: 2 × 20.00 = 40.00
- Товары: 77.50
- Доставка: 10.00
- Итого: 87.50
- Всего единиц: 5
- Сдача: 100.00 − 87.50 = 12.50
