## Описание
Консольное приложение для управления планом обработки фотографий. Позволяет добавлять записи, отмечать их как выполненные, искать по названию, удалять и просматривать статистику по количеству снимков.

## Формат данных
Файл data.json содержит список объектов:
- id — уникальный идентификатор.
- title — название.
- category — категория.
- amount — количество снимков (целое число >= 0).
- completed — статус (true/false).

## Запуск
Запустите файл main.py в IDLE (F5) или через командную строку: python main.py
