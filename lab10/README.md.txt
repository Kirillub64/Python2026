# Лабораторная работа №10. Текстовые файлы и обработка ошибок

## Вариант 15
Сумма элементов с чётной суммой индексов строки и столбца: `(i + j) % 2 == 0`.

## Формат matrix.txt
- Первая строка: два положительных целых числа — количество строк и столбцов.
- Далее ровно указанное количество строк, в каждой ровно указанное количество целых чисел.
- Лишние и пустые строки — ошибка формата.
- Один перевод строки после последней строки данных допустим.

## Файлы
- `files_lab.py` — `read_matrix(path)` и `selected_sum(matrix)`
- `table.py` — `row_sums`, `column_sums` (копия из работы №9)
- `main.py` — `read_positive_integer()` и основная программа с записью отчёта
- `test_files.py` — проверки через `assert` и `tempfile`
- `matrix.txt` — входные данные
- `report.txt` — результат работы

## Запуск
python main.py
python test_files.py

## Проверки
- `1 1\n0\n` → `[[0]]`
- Пустой файл → `ValueError`
- Заголовок `0 3` → `ValueError`
- `1 2\n1\n` → `ValueError`
- `1 2\n1 x\n` → `ValueError`
- `1 1\n1\n2\n` → `ValueError`
- Отсутствующий путь → `FileNotFoundError` в `read_matrix`
- `selected_sum([[1, -2, 3], [4, 0, -6]])` → `4`

## Пояснения для защиты
1. **Ошибка формата vs ошибка доступа.** Формат — неверные данные (`ValueError`); доступ — файла нет (`FileNotFoundError`) или нет прав (`OSError`). Это разные ситуации, и обрабатываются они по-разному.
2. **Почему отчёт открывается для записи после проверки входа?** Если открыть `report.txt` в режиме `w` до проверки и данные окажутся неверными, старый отчёт будет стёрт. Поэтому сначала `read_matrix` и вычисления, потом `open(report, "w")`.
3. **Почему входной файл никогда не открывается в режиме `w`?** Режим `w` стирает содержимое. Для чтения используется только `"r"`.
