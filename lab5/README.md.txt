# Лабораторная работа №5. Обработка строк в Python

## Вариант 15

Слово подходит, если оно начинается с гласной из строки `аеёиоуыэюя`.

---

## Состав работы

| Файл | Назначение |
|---|---|
| `normalize.py` | Нормализация текста: удаление пробелов по краям, замена последовательностей пробельных символов одним пробелом, вывод длин и количества слов |
| `palindrome.py` | Проверка текста на палиндром (игнорируются регистр и обычные пробелы `" "`, пунктуация сравнивается как есть) |
| `replace.py` | Замена всех двоеточий `:` на дефисы `-` с подсчётом количества замен |
| `variant.py` | Индивидуальный вариант 15: слова, начинающиеся с гласной из `аеёиоуыэюя` |

---

## Запуск

```bash
python normalize.py
python palindrome.py
python replace.py
python variant.py
