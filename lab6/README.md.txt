# Лабораторная работа №6. Списки в Python

## Вариант 15

Числа, оканчивающиеся на 2 в записи модуля (`abs(n) % 10 == 2`).

---

## Состав работы

| Файл | Назначение |
|---|---|
| `statistics.py` | Статистика по списку целых чисел: количество, сумма, минимум, максимум, среднее с двумя знаками |
| `transform.py` | Новый список с модулями отрицательных чисел; исходный список сохраняется |
| `positions.py` | Все индексы максимального элемента в порядке возрастания |
| `variant.py` | Индивидуальный вариант 15: числа, оканчивающиеся на 2 в записи модуля |

---

## Запуск

```bash
python statistics.py
python transform.py
python positions.py
python variant.py
