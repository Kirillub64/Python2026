## Ответы на вопросы для защиты

### 1. Когда использовать `and`, а когда `or`?

- **`and`** — когда **оба** условия должны быть истинны.
  Пример: `0 <= x <= 5 and 0 <= y <= 3` — точка внутри прямоугольника.
- **`or`** — когда достаточно **хотя бы одного** истинного условия.
  Пример: `value < 0 or value > 100` — число вне допустимого диапазона.

### 2. Почему важен порядок ветвей в `if/elif/else`?

Проверяется **первая подходящая** ветвь.
Если поставить `value <= 94` перед `value <= 44`, то для числа `20` сработает `<= 94` → «Архив растёт», хотя должно быть «Есть место».
Поэтому ветви идут **от узкого к широкому**: сначала 0–44, потом 45–94, потом 95–100.

### 3. Что происходит при равенстве значений?

При равенстве ветви обрабатывают значения одинаково.
Пример: `2, 2, 2` → `a <= b and a <= c` истинно → выводится `2`.
Никаких ошибок не возникает.
